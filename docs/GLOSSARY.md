# Glossary

> The project's shared vocabulary. Specs, code, tests, and UI copy all use these exact terms.
>
> This exists because ambiguity in naming is the most expensive kind: if "account", "user", and
> "profile" mean three things to you and one thing to Claude, every spec after that is subtly
> wrong. Claude adds terms here as they emerge and flags collisions.

| Term | Means | Does **not** mean | Named in code as |
|---|---|---|---|
| | | | |
